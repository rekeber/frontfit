🔄 Reiniciar Aplicación FitLife

⚠️ ADVERTENCIA: Esta acción eliminará TODOS los datos locales de la aplicación. Esto incluye: comidas registradas, ejercicios, historial de perfil, y configuraciones.
¿Cuándo usar esto?
- Cuando veas datos incorrectos que no se corrigen
- Cuando las traducciones no funcionen (PERDER_PESO en lugar de Perder Peso)
- Cuando los datos no se actualicen después de cambiar el perfil
- Cuando veas datos acumulados en lugar de datos diarios

Pasos para Reiniciar:

1 Limpiar localStorage - Elimina todos los datos guardados localmente
2 Limpiar caché del navegador - Presiona Ctrl+Shift+Delete y selecciona "Cached images and files"
3 Recargar la aplicación - Hard refresh para asegurar que todo se recargue
✅ localStorage limpiado correctamente. Ahora limpia la caché del navegador y recarga la aplicación.
Después de reiniciar:
1. Inicia sesión nuevamente
2. Configura tu perfil (peso, objetivo, actividad)
3. Agrega nuevos datos de prueba
4. Verifica que todo funcione correctamente
